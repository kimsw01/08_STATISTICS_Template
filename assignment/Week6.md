# 2단계 확인 문제 ✅

## 문제 1. 가설 세우기

운영진은 새 통계학 과제가 기존 과제보다 만족도를 높이는지 알고 싶습니다.

1. 귀무가설을 써 주세요.
2. 대립가설을 써 주세요.
3. 이 검정에서 관심 있는 값은 무엇인가요?


## 문제 2. p값 해석

새 과제를 경험한 학회원들의 만족도 분석 결과 p = 0.04가 나왔습니다.

1. 유의수준 5%에서 귀무가설을 기각할 수 있나요?
2. p = 0.04가 "새 과제가 무조건 좋다"는 뜻은 아닌 이유를 적어 주세요.
3. 함께 확인하면 좋은 정보는 무엇인가요?


# 3단계 데이터 분석형 문제 🔍

## 문제 1. 결과 해석하기

다음은 과제 개편 전후 만족도 비교 결과입니다.

| 구분 | 평균 만족도 | 표본 크기 | p값 |
| --- | ---: | ---: | ---: |
| 기존 과제 | 3.6점 | 20명 |  |
| 새 과제 | 3.9점 | 20명 | 0.04 |

1. 평균 만족도 차이는 몇 점인가요?
2. p값을 바탕으로 어떤 조심스러운 결론을 말할 수 있나요?
3. 이 결과를 보고 바로 다음 기수 과제를 바꿔도 되는지 판단하려면 어떤 정보를 더 봐야 하나요?


## 문제 2. 오류 상황 구분하기

다음 상황이 `1종 오류`인지 `2종 오류`인지 구분해 주세요.

1. 실제로는 새 과제가 만족도를 높이지 않았는데, 높였다고 결론 내렸다.
2. 실제로는 새 과제가 만족도를 높였는데, 높이지 못했다고 결론 내렸다.
