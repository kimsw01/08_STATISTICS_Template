<h1 align="center">📊 STATISTICS Template</h1>

다트비 8기 통계학 정규과제를 위한 템플릿입니다.  
이번 과제는 『빅데이터 시대, 올바른 인사이트를 위한 통계 101×데이터 분석』 교재 전체를 빠르게 끝내는 것이 아니라, **데이터 분석에 꼭 필요한 통계학의 기초를 부담 없이, 그러나 정확하게 익히는 것**을 목표로 합니다.

---

## 🎯 학습 목표

- 데이터 분석에서 통계학이 왜 필요한지 설명할 수 있습니다.
- 모집단, 표본, 대표성의 의미를 실제 분석 상황에 연결할 수 있습니다.
- 변수 유형과 데이터 분포에 따라 적절한 요약 방식을 고를 수 있습니다.
- 평균, 중앙값, 표준편차, 이상치를 해석할 수 있습니다.
- 표본분포, 표준오차, 신뢰구간을 통해 추정의 불확실성을 이해할 수 있습니다.
- p값과 가설검정을 기계적으로 해석하지 않고, 조심스럽게 설명할 수 있습니다.
- 상관관계와 회귀 결과를 읽되, 인과관계와 혼동하지 않을 수 있습니다.

## 🧩 과제 구성

각 주차 과제는 아래 흐름으로 구성되어 있습니다.

```text
1단계 개념 정리 ✍️
2단계 확인 문제 ✅
3단계 데이터 분석형 문제 🔍
4단계 오류 찾기 🚨
```

### 1단계 개념 정리 ✍️

교재 내용을 길게 요약하기보다, 본인이 중요하다고 생각한 개념을 직접 골라 짧게 정리합니다.  
개념 이름, 개념 설명, 데이터 분석에서 중요한 이유를 중심으로 작성하면 됩니다.

### 2단계 확인 문제 ✅

이번 주에 배운 개념을 바로 확인하는 짧은 문제입니다.  
용어 구분, 간단한 계산, 기본 해석을 통해 개념을 제대로 이해했는지 점검합니다.

### 3단계 데이터 분석형 문제 🔍

다트비 상황이나 간단한 표를 바탕으로, 실제 데이터 분석에서 어떤 판단을 내려야 하는지 연습합니다.  
숫자를 계산하는 것보다 **계산한 결과를 어떻게 해석할지**에 집중합니다.

### 4단계 오류 찾기 🚨

통계적으로 부적절한 문장을 읽고, 왜 잘못되었는지 설명한 뒤 더 적절한 문장으로 고쳐 씁니다.  
데이터 분석에서 자주 나오는 과도한 일반화, p값 오해, 상관관계와 인과관계 혼동을 줄이는 것이 목표입니다.

## 📂 제출 방법

1. `assignment` 폴더에서 해당 주차의 `.md` 파일을 확인합니다.
2. 개인 과제 제출 방식에 맞춰 답안을 작성합니다.
3. 개념 정리는 길게 베끼기보다, 본인의 언어로 짧고 명확하게 작성합니다.
4. 확인 문제와 데이터 분석형 문제는 계산 과정과 해석을 함께 남깁니다.
5. 오류 찾기 문항에서는 단순히 "틀렸다"가 아니라, 왜 부적절한지와 어떻게 고쳐야 하는지를 함께 작성합니다.
